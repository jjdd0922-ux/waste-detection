# waste-detection
waste classification
Project
Waste Classifier is a project designed to classify waste into three categories:

- E-waste
- Plastic
- Metal

Identifying different types of wastes for segregation/recycing.

## Features

- Waste classification
- E-waste detection
- Plastic waste detection
- Metal waste detection
